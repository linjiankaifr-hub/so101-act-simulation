# ACT动作执行长度与外力干扰：预先固定的实验协议

日期：2026-10-20。目的：为具身智能／机器人学习算法面试形成一个可解释、可复现、有失败证据的主项目。

## 本轮问题与范围

同一个ACT模型每次都预测30步，分别只执行前5、10或30步，再根据新图像重新预测。在相同初始条件下，比较正常任务和一次固定外力干扰下的完成率、错误类型、推理开销。探究更频繁的视觉反馈是否一定有益。

沿用已有环境、策略、成功判据和模型，不训练新模型，不从最终测试选择新超参数。不修改旧实验核心代码、协议、数据、模型和成绩。新增脚本独立输出results/closed_loop。

这是一组现有代码上的受控评测。它不构成新算法、完整失败恢复控制器或真机部署。若短窗口效果不佳，先记录阶段停滞等现象，不自动加入最终测试失败数据重训。

## 固定设置

| 项目 | 约定 |
| --- | --- |
| 权重 | checkpoints/background_control/deploy，开始前固定；普通图像训练，无桌色增强 |
| 输入 | 两路96×96 RGB＋6维自身关节位置；无方块真值输入 |
| 输出 | 6维关节位置目标rad |
| 预测长度 | 30步，不改变权重 |
| 执行长度 | 5、10、30步，全部报告 |
| 控制频率 | 20Hz仿真时间；名义查询频率4、2、0.67Hz |
| 任务 | 随机位置红方块抓起、放入固定区域、松手、稳定1秒 |
| 超时 | 300控制步＝15秒仿真时间 |
| 成功 | 原verified-pinch-lift-release-v2，双侧夹爪接触并抬高超过4.5cm等条件不变 |
| 开发场景 | 23000—23019，共20个；3窗口×2条件＝120回合 |
| 正式场景 | 70000—70099，共100个；3窗口×2条件＝600回合 |
| 模型种子 | 沿用既有单训练种子42；本轮不是多训练种子实验 |

新场景与既有训练、验证、开发、最终测试分区不重叠。所有窗口和条件配对使用相同种子；600回合只有100个不同初始条件，不能称为600个独立场景。开发成绩仅用于检查实验链路，不选择窗口或干扰参数。

## 外力条件

第37和38个控制步（零起算，仿真时间1.85—1.95秒）对方块质心施加世界y方向0.12N外力。偶数种子+y，奇数种子−y；无力矩。方块质量0.01kg、摩擦参数沿用环境。总持续0.1秒，最大外力冲量0.012N·s；实际位移由接触和摩擦决定，不预设几厘米。

使用MuJoCo xfrc_applied，不写方块位置、不绑定物体。每步先清理上一外力，时间窗结束后归零，reset再次清理。本轮不按抓取阶段触发外力，所以不同窗口触发时可能处于不同动作阶段；结论是固定时刻扰动下的任务鲁棒性，不能单凭成功率声称“抓取失败后的恢复率”。

记录脉冲起始位置、脉冲内位移和是否施加。标准组同样记录这一时间窗内自然位移，便于识别物理影响。动作策略看不到力、物体位置或成功标志。

## 测量与证据

- 逐回合成功、有效抓起、失败类型、控制步数、查询次数、最终目标误差。
- 成功率给95% Wilson区间；窗口间按相同种子报告双方成功、改善、退步、双方失败。
- 查询延迟计入预处理、同步CUDA推理及动作传回CPU，先暖机；报告P50/P95。队列取动作不计入查询延迟。
- 仿真不随墙钟推理延迟推进，所以名义频率不能当作真机实时性能；本轮没有延迟注入实验。
- 每个条件保存首个成功／失败真实观测帧与逐步轨迹，代表视频按真实时间戳展示。查询间隔画面是采样保持，不能叫逐帧录像。
- 模型文件、核心源码、场景XML、精确种子、外力和全部旧模型SHA256写入protocol.json；每条件缓存必须同时验证身份和完整逐回合记录。
- 不完整结果保留为interrupted目录；正式结果不混入手工演示。

## 判断与下一步

不预承诺成功率改善。若频繁重规划导致动作推进不足，结合夹爪动作、查询时刻与物体轨迹分析；若改善，区分普通场景和外力场景，并核对退步回合。单个模型、一个方块、受限位置范围和一个脉冲条件均是结论边界。

后续多训练种子、阶段自适应窗口或纠错示范训练应另设开发／最终分区，不能反复用70000—70099调到满意。当前工作保留全部负结果。

## 运行

PowerShell在项目目录执行：`./run_closed_loop.ps1`；只读状态：`./run_closed_loop.ps1 -Status`。

底层入口是scripts/closed_loop_experiment.py；报告与审计scripts/closed_loop_report.py；完整回归scripts/test.sh。
